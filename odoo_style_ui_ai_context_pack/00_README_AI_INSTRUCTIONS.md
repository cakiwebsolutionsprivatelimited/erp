# AI Instructions - Odoo-Style Modular SaaS UI

## Product
Build the frontend UI for an Odoo-style modular SaaS business platform for Indian SMEs.

## Important Legal/Design Boundary
Do NOT copy Odoo exactly. Do not copy its exact colors, icons, layout pixel-for-pixel, wording, logo, or brand identity.
Use Odoo only as inspiration for:
- modular app launcher
- installed apps concept
- common business-app layout
- list/form/kanban/calendar/dashboard views
- app switcher style navigation
- integrated app-suite experience

Create an original UI with a clean, premium, Indian SME-friendly SaaS identity.

## Current Goal
Build a fully functional UI prototype with demo data only.
No backend integration yet.
The UI should simulate a real product so the founder/team can review workflows before backend development.

## Required Stack
- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- shadcn/ui-style components
- Lucide-style icons
- Zustand or React Context for client state
- Demo data from local JSON/TypeScript files
- No real backend calls in Step 1

## Output
Create a working frontend app with:
- tenant product UI
- app launcher
- CRM demo module
- generic list/form/kanban/dashboard patterns
- settings screens
- demo auth/login
- seeded demo data
