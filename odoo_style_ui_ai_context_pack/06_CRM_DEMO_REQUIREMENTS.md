# CRM Demo App Requirements

## Goal
CRM should feel fully functional using demo data.

## CRM Views
Dashboard, Leads List, Lead Detail, Lead Create/Edit Form, Pipeline Kanban, Follow-up Calendar, Customers, Quotations placeholder, Reports placeholder.

## Lead Workflow
New → Contacted → Interested → Quotation Sent → Negotiation → Won / Lost

## Lead Fields
id, name, company, phone, email, source, status, stage, assignedTo, nextFollowUpAt, expectedValue, probability, notes, createdAt.

## Lead Detail Tabs
Overview, Follow-ups, Notes, Activities, Quotations, Files placeholder.

## Demo Actions
Add lead, edit lead, delete lead, change lead stage, drag lead in kanban, add note, add follow-up, mark follow-up complete, convert lead to customer.
