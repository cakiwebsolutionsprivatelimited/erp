# Sprint Plan for UI-First Product Prototype

## Sprint 1: Project Foundation
Setup Next.js + TypeScript + Tailwind, component structure, routes, demo data folder, app shell, and login.

## Sprint 2: App Launcher + Product Shell
Build app launcher, app cards, status badges, topbar/sidebar, app switcher, notifications/profile dropdown.

## Sprint 3: CRM Demo App
CRM dashboard, leads list, lead form, lead detail, activity timeline, notes/follow-ups, customers.

## Sprint 4: Kanban + Calendar
Pipeline kanban, drag/drop lead stages, follow-up calendar, follow-up completion.

## Sprint 5: Settings Foundation
Company settings, users, roles and permissions, active apps, plan usage.

## Sprint 6: Polish
Responsive fixes, empty/loading/error states, demo reset, UX review.
