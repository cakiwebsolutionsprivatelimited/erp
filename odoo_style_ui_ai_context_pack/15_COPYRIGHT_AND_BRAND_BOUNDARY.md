# Copyright and Brand Boundary

## Do Not Copy
- Odoo logo
- Odoo icons
- Exact colors
- Exact page layout
- Exact wording
- Exact screenshots
- Pixel-perfect clone of Odoo backend UI
- Any Odoo protected assets

## Allowed Inspiration
- Modular app concept
- Installed apps / app launcher pattern
- List / form / kanban / calendar / dashboard views
- App-suite approach
- Business software navigation patterns

## Required Output
Original brand identity and original UI that feels familiar to business software users.
