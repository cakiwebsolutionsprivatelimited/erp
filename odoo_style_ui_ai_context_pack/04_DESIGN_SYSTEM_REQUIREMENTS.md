# Design System Requirements

## Visual Direction
Original Odoo-inspired modular SaaS UI. Do not copy Odoo exactly.

## Layout Principles
- App launcher first
- Clean topbar
- Left sidebar inside apps
- Consistent control panel above content
- Large content zone
- Reusable views: dashboard, list, form, kanban, calendar, report

## Color Direction
Choose an original professional palette: indigo, blue, teal, or deep violet primary; soft gray/off-white background; white cards; dark slate text; green success; amber warning; red danger; blue info.

## Components
Button, Input, Select, Multi-select, Date picker, Search box, Card, Stat card, App card, Badge, Tabs, Modal, Drawer, Table, Kanban card, Calendar item, Activity timeline, Empty state, Loading skeleton, Toast, Sidebar, Topbar, Breadcrumbs.

## Responsive
Desktop first, but tablet/mobile should not break. Mobile can use drawer-based navigation.
