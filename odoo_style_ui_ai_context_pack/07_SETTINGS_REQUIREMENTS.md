# Tenant Settings Requirements

## Company Profile
Company name, logo placeholder, GST number, PAN number, phone, email, website, address, city, state, country, timezone, currency.

## Users
User list with name, email, phone, role, status, last active. Actions: invite user demo modal, activate/deactivate user, change role.

## Roles and Permissions
Default roles: Owner, Admin, Sales Manager, Sales Executive, Accountant, Inventory Manager, HR Manager, Support Staff.
Permission matrix grouped by CRM, Sales, Billing, Inventory, HRMS, Settings.

## Active Apps
Show installed apps and available apps. Allow demo install/uninstall.

## Plan and Usage
Current plan, renewal date, users used, storage used, leads used, invoices used, active apps, upgrade CTA.
