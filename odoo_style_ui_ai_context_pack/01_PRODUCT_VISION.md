# Product Vision

## Product Positioning
A modular SaaS business platform for Indian SMEs.

The product helps businesses manage CRM, Sales, Billing, Inventory, Accounts, HRMS, Payroll, Projects, Helpdesk, Field Service, Marketing, Website, Reports, Studio / Customization, and Industry Packs.

## First UI Priority
The first UI should prove the product experience:
1. User logs in
2. User lands on App Launcher
3. User sees installed, available, locked, and coming-soon apps
4. User opens CRM
5. User manages demo leads using dashboard, list, form, kanban, calendar, and activity timeline
6. User explores settings, users, roles, plan usage, and company profile

## Target Users
Business owners, sales managers, sales executives, admin staff, Indian SME operators, service businesses, distributors, retailers, clinics, gyms, and agencies.

## Tone
Professional, clean, practical, fast, trustworthy, not overly fancy.
