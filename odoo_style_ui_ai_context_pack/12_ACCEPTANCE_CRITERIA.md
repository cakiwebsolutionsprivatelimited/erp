# Acceptance Criteria

## Product Experience
- It feels like a modular business app platform.
- User can understand that CRM is one app inside a larger suite.
- App launcher is clear and useful.
- Installed/locked/coming-soon app states work.

## Functionality
- Login works with demo credentials.
- CRM navigation works.
- Leads CRUD works locally.
- Kanban drag/drop works locally.
- Notes/follow-ups work locally.
- Settings screens are usable.
- Demo data persists during session.

## Code Quality
- Components are reusable.
- Demo data is separated from UI components.
- Types are defined.
- Routes are clean.
- Folder structure is understandable.
- Future Laravel API replacement is easy.

## Design Quality
- Original UI, not copied from Odoo.
- Clean SaaS look.
- Responsive enough for tablet/mobile.
- Consistent spacing and typography.
- Business-friendly, not childish.

## Backend Readiness
- Service functions exist for demo data.
- API contracts are documented.
- No component directly depends on hard-coded data.
