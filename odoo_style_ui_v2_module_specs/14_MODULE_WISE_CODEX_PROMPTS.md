# Module-wise Codex Prompts

## Prompt 1: CRM Module
Read the V2 UI module specs. Build the CRM module in full demo mode. Follow 03_CRM_MODULE_DETAILED_SPEC.md exactly. CRM must include dashboard, leads list, lead form, lead detail, pipeline kanban, follow-up calendar, customers, quotations placeholder, and reports placeholder. All demo actions should work locally using local state/localStorage. Do not connect backend APIs.

## Prompt 2: Sales + Quotations + Subscriptions
Read 04_SALES_QUOTATIONS_SUBSCRIPTIONS_SPEC.md. Build Sales module with dashboard, quotations, sales orders, products/services, subscriptions, reports, and sales settings. Quotations must calculate GST locally and support status changes. Use demo data only.

## Prompt 3: Finance + Billing + GST
Read 05_FINANCE_BILLING_ACCOUNTS_EXPENSES_SPEC.md. Build Finance module with dashboard, invoices, GST invoice form, payments, expenses, ledgers, and reports. Invoice calculations must work locally including GST fields.

## Prompt 4: Inventory
Read 06_INVENTORY_PRODUCTS_STOCK_PURCHASE_WAREHOUSE_SPEC.md. Build Inventory module with products, stock, purchase, suppliers, warehouses, stock transfers, and reports. Demo CRUD must work locally.

## Prompt 5: Services
Read 07_SERVICES_PROJECTS_TASKS_HELPDESK_FIELD_SERVICE_SPEC.md. Build Projects, Tasks, Helpdesk, Field Service and Work Orders UI with local demo data and drag/drop task board.

## Prompt 6: HR
Read 08_HR_EMPLOYEES_ATTENDANCE_LEAVE_PAYROLL_SPEC.md. Build HR module with employees, attendance, leave, payroll, documents, and HR reports. Demo actions must work locally.

## Prompt 7: Website
Read 09_WEBSITE_BUILDER_LANDING_FORMS_SPEC.md. Build Website module with pages, landing pages, forms, submissions, themes, SEO settings, and demo conversion of form submission to CRM lead.

## Prompt 8: Marketing
Read 10_MARKETING_EMAIL_WHATSAPP_SMS_CAMPAIGNS_SPEC.md. Build Marketing module with campaigns, email, WhatsApp, SMS, audience, templates, and reports. Demo scheduling and preview should work locally.

## Prompt 9: Productivity
Read 11_PRODUCTIVITY_NOTES_DOCUMENTS_APPROVALS_CHAT_SPEC.md. Build Notes, Documents, Approvals and Chat module with demo local actions.

## Prompt 10: Customization / Studio
Read 12_CUSTOMIZATION_STUDIO_SPEC.md. Build Studio module with custom fields, workflows, form builder, automation rules, and custom report placeholders.

## Prompt 11: Industry Packs
Read 13_INDUSTRY_PACKS_SPEC.md. Build industry pack pages for Pharmacy, Gym, Clinic, Distributor, and Service Company. Each pack should show dashboard, included modules, setup checklist, and demo placeholder workflows.
