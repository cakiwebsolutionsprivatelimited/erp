# App Launcher Refinement Spec

## Current Status
The App Launcher is already created. Refine it to behave like the central tenant home.

## Required Improvements
- Group apps by category.
- Show app count per category.
- Add search by app name, category, and description.
- Add status filter: Installed, Available, Locked, Coming Soon.
- Add trial/subscription banner.
- Add company switcher placeholder.
- Add app quick actions: Open, Install demo, Upgrade required, Coming soon.
- Add Recently opened apps.
- Add Recommended for your business.
