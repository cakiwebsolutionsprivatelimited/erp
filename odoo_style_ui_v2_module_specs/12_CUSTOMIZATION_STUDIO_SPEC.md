# Customization, Custom Fields, Workflows and Form Builder Module Detailed UI Requirement

## Purpose
Allow tenant admins to customize fields, workflows, forms, and automation rules in a controlled way.

## Sidebar
Dashboard, Custom Fields, Workflows, Form Builder, Automation Rules, Custom Reports, Settings.

## Custom Fields
Fields:
Module, Entity, Field label, Field key, Field type, Required, Visible in list, Visible in form, Default value, Status.

Field types:
Text, Number, Date, Select, Multi-select, Checkbox, File placeholder.

## Workflows
Examples:
Lead stages, Ticket statuses, Task statuses, Approval statuses.

Editor:
Workflow name, Module, Stages, Drag/drop stage order, Color/status, Rules placeholder.

## Form Builder
UI:
Left field palette, Center form canvas, Right properties panel.

Sections:
Add section, Add field, Rearrange fields, Required/optional, Preview form.

## Automation Rules
Examples:
When lead stage becomes Quotation Sent, create follow-up after 2 days.
When invoice is overdue, create reminder task.
When ticket priority is high, notify manager.

Fields:
Rule name, Trigger, Condition, Action, Status.

## Demo Functionality
Add custom field locally, modify workflow stages, build demo form layout, create automation rule placeholder.
