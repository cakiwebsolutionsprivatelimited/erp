# CRM Module Detailed UI Requirement

## Purpose
Manage leads, opportunities, follow-ups, customers, communication history, and sales pipeline.

## Sidebar
Dashboard, Leads, Pipeline, Follow-ups, Customers, Activities, Quotations, Reports, CRM Settings.

## CRM Dashboard
Widgets:
- Total leads, New leads, Follow-ups due today, Overdue follow-ups
- Deals won, Deals lost, Expected revenue, Conversion rate

Charts:
- Leads by source, Leads by stage, Monthly lead trend, Sales forecast

Tables:
- Today's follow-ups, Recently created leads, High-value opportunities

Quick actions:
- Add Lead, Import Leads, Schedule Follow-up, Create Quotation

## Leads List
Columns:
- Lead name, Company, Phone, Email, Source, Stage, Assigned to
- Next follow-up, Expected value, Probability, Status, Created date, Actions

Toolbar:
- Search, stage filter, source filter, assigned user filter, date filter, import, export, Add Lead

Bulk actions:
- Assign user, Change stage, Add tag, Delete, Export selected

## Lead Create/Edit Form
Sections:
- Lead information, Contact information, Company information, Requirement details, Sales details, Assignment, Follow-up plan, Notes

Fields:
- Lead name, Company name, Phone, Alternate phone, Email, City, State
- Lead source, Requirement, Expected value, Probability, Stage, Assigned user
- Next follow-up date/time, Priority, Tags, Notes

## Lead Detail Page
Header:
- Lead name, Company, Stage badge, Expected value, Assigned user, Quick actions

Tabs:
- Overview, Follow-ups, Activities, Notes, Quotations, Files, Timeline

Actions:
- Edit lead, Change stage, Add note, Add follow-up, Create quotation, Convert to customer, Mark won/lost

## Pipeline Kanban
Columns:
New, Contacted, Interested, Quotation Sent, Negotiation, Won, Lost

Card data:
Lead name, Company, Expected value, Probability, Next follow-up, Assigned user, Priority

Actions:
- Drag/drop stage, Quick note, Quick follow-up, Open lead detail

## Follow-up Calendar
Views:
Today, Week, Month, Overdue, Assigned to me

Actions:
Mark complete, Reschedule, Add note, Open lead/customer

## Customers
List columns:
Customer name, Company, Phone, Email, City, Total deal value, Last contact date, Owner, Status

Detail tabs:
Overview, Contacts, Leads history, Quotations, Invoices placeholder, Communication, Notes, Files

## Reports
Lead source, Stage-wise, User performance, Follow-up performance, Won/lost, Expected revenue

## Demo Functionality
Add/edit/delete lead, change stage, kanban drag/drop, add note, add follow-up, mark follow-up complete, convert lead to customer, filter/search leads.
