# Services, Projects, Tasks, Helpdesk and Field Service Module Detailed UI Requirement

## Purpose
Manage projects, tasks, support tickets, service requests, technician visits, and work orders.

## Sidebar
Dashboard, Projects, Tasks, Helpdesk Tickets, Field Service, Work Orders, Calendar, Reports, Service Settings.

## Dashboard
Widgets:
Active projects, Open tasks, Overdue tasks, Open tickets, Field visits today, Completed work orders, SLA breached tickets.

Charts:
Ticket status, Task completion, Technician workload, Project progress.

## Projects
Columns:
Project name, Customer, Manager, Start date, Deadline, Progress, Status.

Detail tabs:
Overview, Tasks, Milestones, Team, Files placeholder, Time logs, Notes.

## Tasks
Board columns:
To Do, In Progress, Review, Done, Blocked.

Fields:
Title, Project, Assigned to, Priority, Due date, Description, Checklist, Status.

## Helpdesk
Columns:
Ticket ID, Customer, Subject, Category, Priority, Assigned to, Status, Created date, SLA.

Statuses:
Open, Assigned, In Progress, Waiting Customer, Resolved, Closed.

Detail tabs:
Conversation, Internal notes, Customer details, Related work order, Attachments.

## Field Service
Fields:
Service request, Customer, Location, Technician, Visit date/time, Service type, Status, Materials used, Customer signature placeholder, Payment collected.

Statuses:
Scheduled, On the Way, In Progress, Completed, Cancelled.

## Work Orders
Fields:
Work order number, Customer, Technician, Items/services, Visit summary, Charges, Payment status.

## Reports
Project progress, Task performance, Ticket SLA, Technician visit, Work order revenue.

## Demo Functionality
Create project, create task, drag task board, create ticket, assign ticket, update status, schedule field visit, complete work order demo.
