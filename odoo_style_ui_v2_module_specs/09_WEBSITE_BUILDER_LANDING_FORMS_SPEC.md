# Website Builder, Landing Pages and Forms Module Detailed UI Requirement

## Purpose
Allow tenants to create simple pages, landing pages, forms, and capture enquiries directly into CRM.

## Sidebar
Dashboard, Pages, Landing Pages, Forms, Submissions, Themes, SEO Settings, Website Settings.

## Website Dashboard
Widgets:
Published pages, Draft pages, Form submissions, Leads captured, Page views placeholder, Conversion rate placeholder.

## Pages
Columns:
Page title, URL slug, Status, Last updated, Created by, Actions.

Page Form:
Title, Slug, Meta title, Meta description, Page sections, Publish status.

## Landing Pages
Fields:
Landing page name, Campaign, URL slug, Hero title, CTA button, Form attached, Status.

## Forms
Builder fields:
Form name, Fields list, Required fields, Submit action, CRM lead mapping.

Field types:
Text, Phone, Email, Select, Textarea, Date, File placeholder.

## Submissions
Columns:
Form name, Visitor name, Phone, Email, Submitted date, Converted to lead, Actions.

## Demo Functionality
Create page demo, create form demo, view submissions, convert form submission to CRM lead.
