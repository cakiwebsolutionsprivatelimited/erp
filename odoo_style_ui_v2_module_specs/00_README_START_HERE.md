# V2 UI Module Requirement Pack - Odoo-Style SaaS for Indian SMEs

## Purpose
This pack expands the existing UI context pack. The App Launcher is now created. Next, build each app/module screen with detailed UI requirements and Codex prompts.

## Product Flow
Login → Tenant App Launcher → Open App → App-specific dashboard/list/form/kanban/calendar/report screens.

## Important Rule
Do not copy Odoo exactly. Build an original Odoo-style modular business app UI.

## Build Strategy
Build one module at a time:
1. Refine App Launcher.
2. Build CRM first in full demo mode.
3. Build Sales + Quotations.
4. Build Billing/GST.
5. Then Inventory, HR, Services, Marketing, Website, Productivity, Customization, and Industry Packs.
